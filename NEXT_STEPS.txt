常见问题
================================================================================

Q: 遇到 "fatal: could not read Username"？
A: 检查网络连接，或使用 SSH Key (参考 GITHUB_ACTIONS_GUIDE.md)

Q: Permission denied?
A: 检查用户名是否正确 (happypb2)，或使用 Personal Access Token

Q: 不知道密码？
A: 访问 GitHub → Settings → Developer settings → Personal access tokens
   创建新的 token，勾选 "repo" 权限
   使用 token 作为密码
